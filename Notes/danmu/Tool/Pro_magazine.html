                    <h3 style="margin: 0; font-size: 15px; font-weight: 700; color: #1e293b;">一、值得学习的句子结构</h3>
                </summary>
                <div class="litit-fold-content">
                    <ol style="margin: 0; padding-left: 18px;">
                        <li class="litit-target-sentence" style="margin-bottom: 12px;">
                            <strong class="litit-en-sentence">Yemen's Houthi fighters – already a threat to global shipping – are an increasing threat to Saudi Arabia. And they provide leverage for their backers in Iran, Saudi's regional rival.</strong><br>
                            <span class="litit-zh-sentence">也门胡塞武装——本就已是全球航运的威胁——如今对沙特阿拉伯构成了越来越大的威胁。而且他们为其在伊朗（沙特的地区竞争对手）的支持者提供了谈判筹码。</span>
                            <ul style="list-style-type: circle; margin: 4px 0 0 0; padding-left: 16px;">
                                <li style="margin-bottom: 3px;"><strong>双破折号插入语</strong>：already a threat to global shipping 作为同位语补充说明主语既有的威胁属性。</li>
                                <li style="margin-bottom: 3px;"><strong>provide leverage for...</strong>：为……提供筹码/影响力</li>
                                <li style="margin-bottom: 3px;"><strong>regional rival</strong>：地区竞争对手/宿敌</li>
                            </ul>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 12px;">
                            <strong class="litit-en-sentence">As jitters run through international energy markets, hunger menaces weary Yemenis forced to flee this latest spasm of violence.</strong><br>
                            <span class="litit-zh-sentence">当恐慌情绪在国际能源市场蔓延时，饥饿正威胁着那些被迫逃离最新一轮暴力冲突、疲惫不堪的也门人。</span>
                            <ul style="list-style-type: circle; margin: 4px 0 0 0; padding-left: 16px;">
                                <li style="margin-bottom: 3px;"><strong>jitters run through...</strong>：紧张/恐慌情绪席卷……</li>
                                <li style="margin-bottom: 3px;"><strong>menace</strong>：威胁；危及（动词）</li>
                                <li style="margin-bottom: 3px;"><strong>spasm of violence</strong>：一阵突发的暴力冲突（spasm 原意为痉挛、抽搐，比喻间歇性爆发的冲突）</li>
                            </ul>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 12px;">
                            <strong class="litit-en-sentence">The Houthi attack - the deadliest on Saudi soil in more than a decade - sent shockwaves around the region and punctured the kingdom's sense of security.</strong><br>
                            <span class="litit-zh-sentence">胡塞武装的这次袭击——十多年来在沙特本土发生的最致命袭击——在整个地区引发了震动，并刺破了该王国的安全感。</span>
                            <ul style="list-style-type: circle; margin: 4px 0 0 0; padding-left: 16px;">
                                <li style="margin-bottom: 3px;"><strong>on Saudi soil</strong>：在沙特领土/本土上</li>
                                <li style="margin-bottom: 3px;"><strong>send shockwaves around...</strong>：在……引发震动/冲击波</li>
                                <li style="margin-bottom: 3px;"><strong>puncture the sense of security</strong>：刺破安全感（极为生动的动词隐喻，像扎破气球一样）</li>
                            </ul>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 12px;">
                            <strong class="litit-en-sentence">If there is a new attempt at mediation – and there is some speculation about this - they may drive a hard bargain.</strong><br>
                            <span class="litit-zh-sentence">如果有新的调解尝试——目前确实有一些这方面的猜测——他们可能会漫天要价（提出苛刻的条件）。</span>
                            <ul style="list-style-type: circle; margin: 4px 0 0 0; padding-left: 16px;">
                                <li style="margin-bottom: 3px;"><strong>attempt at mediation</strong>：调解/斡旋的尝试（注意介词用 at）</li>
                                <li style="margin-bottom: 3px;"><strong>drive a hard bargain</strong>：讨价还价极为苛刻；极力争先/寸步不让</li>
                            </ul>
                        </li>
                    </ol>
                </div>

                    <h3 style="margin: 0; font-size: 15px; font-weight: 700; color: #1e293b;">二、值得积累的短语和固定搭配</h3>
                </summary>
                <div class="litit-fold-content">
                    <ul style="list-style-type: square; margin: 0; padding-left: 18px; line-height: 1.6;">
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>pro-government forces</strong>: 亲政府部队<br>
                            <strong class="litit-en-sentence">We were travelling with Yemen's pro-government forces through the desert.</strong><br>
                            <span class="litit-zh-sentence">我们正与也门的亲政府部队一起穿越沙漠。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>catch glimpses of</strong>: 瞥见；隐约看到<br>
                            <strong class="litit-en-sentence">We were catching glimpses of the Arabian Sea in the distance.</strong><br>
                            <span class="litit-zh-sentence">我们隐约瞥见了远处的阿拉伯海。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>forbidding mountain peaks</strong>: 险峻/令人生畏的山峰<br>
                            <strong class="litit-en-sentence">The soldiers pointed toward the forbidding mountain peaks ahead.</strong><br>
                            <span class="litit-zh-sentence">士兵们指着前方那些令人生畏的险峻山峰。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>dislodge from</strong>: 从……驱逐/赶走<br>
                            <strong class="litit-en-sentence">Houthi rebels were dislodged from here just days ago.</strong><br>
                            <span class="litit-zh-sentence">胡塞叛军就在几天前被从这里赶走了。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>global implications</strong>: 全球性影响<br>
                            <strong class="litit-en-sentence">Here in the far corners of the Middle East, a war is being waged with global implications.</strong><br>
                            <span class="litit-zh-sentence">在中东这个偏远的角落，一场具有全球性影响的战争正在打响。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>entrenched civil war</strong>: 根深蒂固的/旷日持久的内战<br>
                            <strong class="litit-en-sentence">Yemen's entrenched civil war is now impossible to ignore.</strong><br>
                            <span class="litit-zh-sentence">也门旷日持久的内战如今已无法被忽视。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>slam into</strong>: 猛烈撞击/击中<br>
                            <strong class="litit-en-sentence">Missiles slammed into the international airport in Riyadh this weekend.</strong><br>
                            <span class="litit-zh-sentence">本周末，多枚导弹猛烈击中了利雅得的国际机场。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>provide leverage for</strong>: 为……提供筹码<br>
                            <strong class="litit-en-sentence">The fighters provide leverage for their backers in regional negotiations.</strong><br>
                            <span class="litit-zh-sentence">这些武装分子为他们背后的支持者在地区谈判中提供了筹码。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>sweep into</strong>: 席卷；长驱直入<br>
                            <strong class="litit-en-sentence">The Houthis swept into the capital, Sanaa, in 2014.</strong><br>
                            <span class="litit-zh-sentence">胡塞武装于2014年长驱直入，占领了首都萨那。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>oust the government</strong>: 推翻/罢黜政府<br>
                            <strong class="litit-en-sentence">The rebels seized the capital, ousting the internationally recognised government.</strong><br>
                            <span class="litit-zh-sentence">叛军占领了首都，推翻了国际公认的政府。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>strategic maritime corridor</strong>: 战略海上走廊/航道<br>
                            <strong class="litit-en-sentence">Fighters remain on high ground overlooking a strategic maritime corridor.</strong><br>
                            <span class="litit-zh-sentence">武装分子仍盘踞在俯瞰一条战略海上走廊的高地上。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>a lightning advance</strong>: 闪电般的推进（攻势）<br>
                            <strong class="litit-en-sentence">The Houthis seized the area after a lightning advance in September.</strong><br>
                            <span class="litit-zh-sentence">胡塞武装在九月发动闪电推进后占领了该地区。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>wrest back</strong>: 艰难夺回<br>
                            <strong class="litit-en-sentence">The commander claims pro-government forces have wrested back about 85% of the territory.</strong><br>
                            <span class="litit-zh-sentence">指挥官声称亲政府部队已经艰难夺回了约85%的领土。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>improvised explosive devices (IEDs)</strong>: 简易爆炸装置（路边炸弹）<br>
                            <strong class="litit-en-sentence">Five military vehicles apparently hit improvised explosive devices planted by the rebels.</strong><br>
                            <span class="litit-zh-sentence">五辆军车显然撞上了叛军埋设的简易爆炸装置。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>a tableau of suffering</strong>: 一幅苦难的画面<br>
                            <strong class="litit-en-sentence">As we left the area, we saw a tableau of suffering with families seeking shelter.</strong><br>
                            <span class="litit-zh-sentence">离开该地区时，我们看到了一幅流离失所的家庭四处寻找庇护的苦难画面。</span>
                        </li>
                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>with just the clothes on our backs</strong>: 只穿着身上的衣服（形容身无分文、狼狈逃难）<br>
                            <strong class="litit-en-sentence">We had to run from our homes, with just the clothes on our backs.</strong><br>
                            <span class="litit-zh-sentence">我们不得不逃离家园，全身上下只有身上穿的衣服。</span>

                        <li class="litit-target-sentence" style="margin-bottom: 10px;">
                            <strong>make no distinctions</strong>: 一视同仁；不做区分<br>
                            <strong class="litit-en-sentence">When treating wounded soldiers in the ward, the doctors make no distinctions.</strong><br>
                            <span class="litit-zh-sentence">在病房里救治受伤士兵时，医生们一视同仁，不做任何区分。</span>

            <details class="litit-fold">
                <summary>
                    <h3 style="margin: 0; font-size: 15px; font-weight: 700; color: #1e293b;">三、新闻英语中的高价值表达</h3>
                </summary>
                <div class="litit-fold-content">
                    <ol style="margin: 0; padding-left: 18px;">
                        <li style="margin-bottom: 12px;">
                            <strong>dislodge / wrest back</strong><br>
                            军事报道中的两个核心词。<strong>dislodge</strong> 指把敌人从坚固的据点或阵地中“拔除、强行赶走”；<strong>wrest back</strong> 则指经过激烈争夺后“强行夺回”（失地或控制权），比普通动词 take back 更具力量感。
                        </li>
                        <li style="margin-bottom: 12px;">
                            <strong>entrenched</strong><br>
                            根深蒂固的；陷入僵局的。<br>
                            词源来自 trench（战壕）。在新闻中，<i>entrenched civil war</i> 既指双方挖好战壕对峙，也引申为战争已经持续太久、各方利益盘根错节，极难结束。
                        </li>
                        <li style="margin-bottom: 12px;">
                            <strong>leverage</strong><br>
                            筹码；影响力；杠杆作用。<br>
                            外交与地缘政治高频词。文中指胡塞武装的壮大，为伊朗在与沙特及西方的博弈中提供了重要的政治筹码（provide leverage）。
                        </li>
                        <li style="margin-bottom: 12px;">
                            <strong>puncture one's sense of security</strong><br>
                            刺破某人的安全感。<br>
                            极其地道的新闻修辞。用 puncture（刺穿轮胎/气球）来形容袭击事件瞬间打破了一国长期以来的安全幻觉。
                        </li>
                    </ol>
                </div>
            </details>

            <details class="litit-fold">
                <summary>
                    <h3 style="margin: 0; font-size: 15px; font-weight: 700; color: #1e293b;">四、最值得优先掌握的句型</h3>
                </summary>
                <div class="litit-fold-content">
                    <ol style="margin: 0; padding-left: 18px;">
                        <li style="margin-bottom: 8px;">

                            <strong>As jitters run through A, B menaces C.</strong><br>

                        </li>
                        <li style="margin-bottom: 8px;">
                            <strong>We had to run, with just the clothes on our backs.</strong><br>

                        </li>

        <h2 class="section-header" style="border-left-color: #0d9488;">💡 幕后冷知识 (Fun Facts)</h2>
        <ul style="padding-left:18px; line-height:1.8; color:#334155; font-size:14.5px; margin-bottom:24px; word-break:break-word;">
            <li style="margin-bottom: 8px;"><strong>“悲叹之门”曼德海峡（Bab al-Mandab）：</strong> 文中提到的这一战略海上走廊，连接着红海与亚丁湾，是苏伊士运河航线的必经咽喉。在阿拉伯语中，Bab al-Mandab 的字面意思是“泪水之门”或“悲叹之门”（传说远古地震撕裂大陆导致无数人溺亡）。如今，这里控制着全球极其重要的石油和贸易运输，一旦被胡塞武装彻底封锁，全球供应链与油价都将随之剧烈震荡。</li>
            <li style="margin-bottom: 8px;"><strong>极其松散的“反胡塞联盟”：</strong> 报道中记者特意用了一个重复强调的短语“part of the loose – very loose – alliance”（松散——非常松散——的联盟）。这是因为与胡塞武装作战的也门政府军内部派系林立，比如受采访指挥官所在的“南方部队”（Southern Forces），其背后原本主要由阿联酋支持，带有强烈的南也门独立倾向，与沙特支持的也门合法政府往往同床异梦，仅靠“对抗胡塞”这一共同目标勉强维持合作。</li>
            <li><strong>新闻翻译乌龙与勘误：</strong> 文章末尾附带了一条极具新闻专业主义精神的勘误（Correction）。BBC 最初报道难民老妇 Aisha 是因为害怕“沙特的空袭”而逃难，随后核实发现是现场翻译失误，老妇实际控诉的是袭击其家乡山区的“胡塞武装无人机”。在各方势力交错轰炸的也门，连天上的死神属于哪一方，有时都会在传播中产生混淆。</li>
        </ul>

        const AI_PROMPT = "请分析以下英文段落，并严格按照以下 Markdown 格式输出（不要输出任何额外的废话）：\n\n### 📌 完整翻译\n\n[此处填写完整翻译]\n\n### 📌 Key Expressions\n\n- **[单词或短语]**\n  = [中文释义]\n  （[可选的补充说明，如倒装结构或语境等]）\n\n段落内容：\n";

        // --- 顶部阅读进度条逻辑 ---
        function initProgressBar() {
            const progressBar = document.getElementById('reading-progress');
            if (!progressBar) return;
            window.addEventListener('scroll', () => {
                const scrollTop = document.documentElement.scrollTop || document.body.scrollTop;
                const scrollHeight = document.documentElement.scrollHeight - document.documentElement.clientHeight;
                if (scrollHeight <= 0) return;
                const scrollPercent = (scrollTop / scrollHeight) * 100;
                progressBar.style.width = scrollPercent + '%';
            }, { passive: true });
        }

        async function fetchGroq(text, apiKey, modelName) {
            const res = await fetch('https://api.groq.com/openai/v1/chat/completions', {
                method: 'POST',
                headers: {
                    'Authorization': 'Bearer ' + apiKey,
                    'Content-Type': 'application/json'
                },
                body: JSON.stringify({
                    model: modelName || 'llama-3.3-70b-versatile',
                    messages: [
                        { role: 'system', content: 'You are an English teacher. Output EXACTLY in the requested Markdown format.' },
                        { role: 'user', content: AI_PROMPT + '"' + text + '"' }
                    ],
                    temperature: 0.3
                })
            });
            if (!res.ok) throw new Error('Groq Error: ' + res.status);
            const json = await res.json();
            return json.choices[0].message.content.trim();
        }

        async function fetchCustomAI(text, url, apiKey, modelName) {
            let headers = { 'Content-Type': 'application/json' };
            let bodyData = {};
            if (url.includes('anthropic.com')) {
                headers['x-api-key'] = apiKey;
                headers['anthropic-version'] = '2023-06-01';
                headers['anthropic-dangerous-direct-browser-access'] = 'true';
                bodyData = {
                    model: modelName || 'claude-3-5-sonnet-20241022',
                    max_tokens: 2000,
                    messages: [{ role: 'user', content: AI_PROMPT + '"' + text + '"' }]
                };
            } else if (url.includes('generativelanguage.googleapis.com')) {
                let targetUrl = url;
                if (!targetUrl.includes('key=')) {
                    targetUrl += (targetUrl.includes('?') ? '&' : '?') + 'key=' + apiKey;
                }
                const res = await fetch(targetUrl, {
                    method: 'POST',
                    headers: headers,
                    body: JSON.stringify({
                        contents: [{ parts: [{ text: AI_PROMPT + '"' + text + '"' }] }]
                    })
                });
                if (!res.ok) throw new Error('Gemini Error: ' + res.status);
                const json = await res.json();
                return json.candidates[0].content.parts[0].text.trim();
            } else {
                headers['Authorization'] = 'Bearer ' + apiKey;
                bodyData = {
                    model: modelName || 'gpt-4o-mini',
                    messages: [
                        { role: 'system', content: 'You are an English teacher. Output EXACTLY in the requested Markdown format.' },
                        { role: 'user', content: AI_PROMPT + '"' + text + '"' }
                    ],
                    temperature: 0.3
                };
            }
            const res = await fetch(url, {
                method: 'POST',
                headers: headers,
                body: JSON.stringify(bodyData)
            });
            if (!res.ok) throw new Error('AI Interface Error: ' + res.status);
            const json = await res.json();
            if (json.choices && json.choices.length > 0) return json.choices[0].message.content.trim();
            throw new Error('AI 返回数据异常');
        }

        async function executeAIPipeline(text) {
            const customUrl = localStorage.getItem('CUSTOM_API_URL') || '';
            const customKey = localStorage.getItem('CUSTOM_API_KEY') || '';
            const customModel = localStorage.getItem('CUSTOM_MODEL') || '';
            const groqKey = localStorage.getItem('GROQ_API_KEY') || '';
            const groqModel = localStorage.getItem('GROQ_MODEL') || '';

            if (customUrl && customKey) {
                try {
                    return await fetchCustomAI(text, customUrl, customKey, customModel);
                } catch (err) {
                    if (groqKey) return await fetchGroq(text, groqKey, groqModel);
                    throw err;
                }
            } else if (groqKey) {
                return await fetchGroq(text, groqKey, groqModel);
            } else {
                const userKey = prompt('⚠️ 当前页面未检测到 AI Key！\n为了安全，密匙只储存在您本地浏览器中。\n\n请输入您的 API Key (如 sk-xxx 或 gsk_xxx):');
                if (userKey && userKey.trim()) {
                    const cleanKey = userKey.trim();
                    if (cleanKey.startsWith('gsk_')) {
                        localStorage.setItem('GROQ_API_KEY', cleanKey);
                    } else {
                        localStorage.setItem('CUSTOM_API_KEY', cleanKey);
                        localStorage.setItem('CUSTOM_API_URL', 'https://api.chatanywhere.tech/v1/chat/completions');
                    }
                }
                throw new Error('未设置 AI API Key');
            }
        }

        // --- 降级清理防线：净化污染节点 ---
        function getPurifiedFallbackHTML() {
            const clone = document.documentElement.cloneNode(true);
            const foreignSelectors = [
                'relingo-app', 'relin-highlight', 'relin-hc',
                '[class*="relingo"]', '[data-relin-paragraph]',
                'grammarly-extension', '[data-grammarly-part]',
                '[class*="immersive-translate"]', '[data-immersive-translate]'
            ].join(',');
            clone.querySelectorAll(foreignSelectors).forEach(el => el.remove());

            clone.querySelectorAll('relin-highlight, relin-hc').forEach(t => {
                const frag = document.createDocumentFragment();
                while(t.firstChild) frag.appendChild(t.firstChild);
                t.parentNode.replaceChild(frag, t);
            });

            clone.querySelectorAll('script').forEach(s => {
                if (!s.src.includes('marked.min.js') && s.id !== 'core-engine') s.remove();
            });
            clone.querySelectorAll('style').forEach(s => {
                if (s.id !== 'core-style') s.remove();
            });

            const liveTAs = document.querySelectorAll('.anno-edit');
            clone.querySelectorAll('.anno-edit').forEach((ta, i) => {
                if(liveTAs[i]) ta.textContent = liveTAs[i].value.trim();
                const box = ta.closest('.anno-box');
                if (box) box.style.display = 'none';
                const view = box ? box.querySelector('.anno-view') : null;
                if (view) view.innerHTML = '';
            });

            return '<!DOCTYPE html>\n<html lang="zh-CN">\n' + clone.innerHTML + '\n</html>';
        }

        // --- 内存反向打补丁同步技术 ---
        async function syncToCloud() {
            const ghToken = localStorage.getItem('LITIT_GH_TOKEN') || localStorage.getItem('GH_TOKEN');
            const ghOwner = 'moodHappy';
            const ghRepo = 'dual-read-notes';
            if (!ghToken) return;

            const pathParts = window.location.pathname.split('/');
            const fileName = pathParts.pop();
            const month = pathParts.pop();
            const year = pathParts.pop();
            if(!fileName || !month || !year) return;

            const fileRelPath = 'Summary/' + year + '/' + month + '/' + fileName;

            try {
                const getRes = await fetch('https://api.github.com/repos/' + ghOwner + '/' + ghRepo + '/contents/' + fileRelPath + '?t=' + Date.now(), {
                    headers: { 'Authorization': 'Bearer ' + ghToken },
                    cache: 'no-store'
                });

                let finalHTML = '';
                let sha = '';

                if (getRes.ok) {
                    const fileData = await getRes.json();
                    sha = fileData.sha;
                    const cleanRawHTML = decodeURIComponent(escape(atob(fileData.content.replace(/\n/g, ''))));
                    const parser = new DOMParser();
                    const cleanDoc = parser.parseFromString(cleanRawHTML, 'text/html');

                    const liveTAs = document.querySelectorAll('.anno-edit');
                    const cleanTAs = cleanDoc.querySelectorAll('.anno-edit');
                    liveTAs.forEach((liveTa, index) => {
                        if (cleanTAs[index]) {
                            const val = liveTa.value.trim();
                            cleanTAs[index].textContent = val;
                            const box = cleanTAs[index].closest('.anno-box');
                            if (box) box.style.display = 'none';
                            const view = box ? box.querySelector('.anno-view') : null;
                            if (view) view.innerHTML = '';
                        }
                    });

                    cleanDoc.querySelectorAll('.anno-toggle').forEach(t => {
                        t.classList.remove('has-anno');
                        const ta = t.closest('.content-wrap, .litit-highlight-block')?.querySelector('.anno-edit');
                        if (ta && ta.textContent.trim()) t.classList.add('has-anno');
                    });

                    finalHTML = '<!DOCTYPE html>\n<html lang="zh-CN">\n' + cleanDoc.documentElement.innerHTML + '\n</html>';
                } else {
                    finalHTML = getPurifiedFallbackHTML();
                }

                await fetch('https://api.github.com/repos/' + ghOwner + '/' + ghRepo + '/contents/' + fileRelPath, {
                    method: 'PUT',
                    headers: {
                        'Authorization': 'Bearer ' + ghToken,
                        'Content-Type': 'application/json'
                    },
                    body: JSON.stringify({
                        message: 'Silent purified annotation update',
                        content: btoa(unescape(encodeURIComponent(finalHTML))),
                        sha: sha || undefined
                    })
                });
                console.log('✅ [My Litit] 纯净无污染批注已静默同步至 GitHub');
            } catch(e) {
                console.warn('❌ [My Litit] 同步跳过或失败:', e);
            }
        }

        function scheduleSync() {
            if (syncTimeout) clearTimeout(syncTimeout);
            syncTimeout = setTimeout(() => {
                syncToCloud();
            }, 3000);
        }

        function initAnnotations() {
            document.querySelectorAll('.litit-highlight-block, .content-wrap').forEach(wrap => {
                let content = wrap.querySelector('.content');
                if (!content) {
                    const pText = wrap.querySelector('p');
                    if (pText) {
                        content = document.createElement('div');
                        content.className = 'content';
                        content.style.cssText = 'position:relative; margin:0 0 6px 0; color:#1a202c; font-family:Georgia, serif; line-height:1.7; font-size:15px; word-break:break-word;';
                        content.innerHTML = pText.innerHTML;
                        pText.parentNode.replaceChild(content, pText);
                    }
                }
                if (!content) return;

                if (!content.querySelector('.anno-toggle')) {
                    const toggle = document.createElement('span');
                    toggle.className = 'anno-toggle';
                    toggle.title = '手写批注/笔记';
                    content.appendChild(toggle);
                }
                if (!content.querySelector('.ai-toggle')) {
                    const aiToggle = document.createElement('span');
                    aiToggle.className = 'ai-toggle';
                    aiToggle.title = 'AI智能二次解析';
                    content.appendChild(aiToggle);
                }

                let box = wrap.querySelector('.anno-box');
                if (!box) {
                    box = document.createElement('div');
                    box.className = 'anno-box';
                    box.style.display = 'none';
                    box.innerHTML = '<div class="anno-view markdown-body"></div><textarea class="anno-edit" style="display:none;" placeholder="在此写下笔记或使用 AI 解析..."></textarea>';
                    wrap.appendChild(box);
                }

                const view = box.querySelector('.anno-view');
                const edit = box.querySelector('.anno-edit');
                const toggle = content.querySelector('.anno-toggle');
                const aiToggle = content.querySelector('.ai-toggle');

                if (edit && edit.value.trim()) {
                    toggle.classList.add('has-anno');
                    try {
                        view.innerHTML = (typeof marked !== 'undefined') ? marked.parse(edit.value.trim()) : edit.value.trim();
                    } catch(e){}
                }

                if (aiToggle) {
                    aiToggle.onclick = async (e) => {
                        e.preventDefault();
                        e.stopPropagation();
                        if (aiToggle.classList.contains('loading')) return;

                        if (edit && edit.value.trim() !== '') {
                            const confirmOverwrite = confirm('⚠️ 已经存在批注内容。点击"确定"将使用 AI 解析覆盖现有内容。是否继续？');
                            if (!confirmOverwrite) return;
                        }

                        const pClone = content.cloneNode(true);
                        pClone.querySelectorAll('.anno-toggle, .ai-toggle').forEach(el => el.remove());
                        let pText = pClone.textContent.replace(/https?:\/\/\S+/g, '').trim();
                        if (!pText) return;

                        aiToggle.classList.add('loading');
                        try {
                            const aiContent = await executeAIPipeline(pText);
                            box.style.display = 'block';
                            view.style.display = 'none';
                            edit.style.display = 'block';
                            edit.value = aiContent;
                            edit.focus();
                            edit.blur();
                        } catch (err) {
                            console.error(err);
                        } finally {
                            aiToggle.classList.remove('loading');
                        }
                    };
                }

                if (toggle) {
                    toggle.onclick = (e) => {
                        e.preventDefault();
                        e.stopPropagation();
                        if (box.style.display === 'block') {
                            box.style.display = 'none';
                        } else {
                            box.style.display = 'block';
                            if (!edit.value.trim()) {
                                view.style.display = 'none';
                                edit.style.display = 'block';
                                setTimeout(() => { edit.focus(); }, 150);
                            } else {
                                view.style.display = 'block';
                                edit.style.display = 'none';
                            }
                        }
                    };
                }

                const triggerEdit = (e) => {
                    if(e) { e.preventDefault(); e.stopPropagation(); }
                    view.style.display = 'none';
                    edit.style.display = 'block';
                    edit.value = edit.value; 
                    setTimeout(() => { edit.focus(); }, 150);
                };

                view.addEventListener('dblclick', triggerEdit);

                let lastTap = 0;
                view.addEventListener('touchstart', e => {
                    if (e.touches.length === 2) {
                        triggerEdit(e);
                    } else if (e.touches.length === 1) {
                        const currentTime = new Date().getTime();
                        if (currentTime - lastTap < 500 && currentTime - lastTap > 0) {
                            e.preventDefault();
                            box.style.display = 'none';
                        }
                        lastTap = currentTime;
                    }
                }, {passive: false});

                if (edit && view) {
                    edit.onblur = () => {
                        setTimeout(() => {
                            const newVal = edit.value.trim();
                            try {
                                view.innerHTML = newVal ? ((typeof marked !== 'undefined') ? marked.parse(newVal) : newVal) : '';
                            } catch(e){}
                            edit.style.display = 'none';
                            if (newVal) {
                                view.style.display = 'block';
                                toggle.classList.add('has-anno');
                            } else {
                                view.style.display = 'none';
                                box.style.display = 'none';
                                toggle.classList.remove('has-anno');
                            }
                            if (edit.getAttribute('data-old-val') !== newVal) {
                                edit.setAttribute('data-old-val', newVal);
                                scheduleSync();
                            }
                        }, 150);
                    };
                    edit.setAttribute('data-old-val', edit.value.trim());
                }
            });
        }

        window.addEventListener('DOMContentLoaded', () => {
            initProgressBar();
            initAnnotations();
        });
        window.addEventListener('load', initAnnotations);
    </script>
</body>
